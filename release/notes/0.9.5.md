# 文件夹直传、Everything 一键安装与防火墙放行

- 可以直接把文件夹发给已匹配的设备：拖进来或点「选择文件夹」，会打包成一个 zip 发送。
- 传输记录在重启后仍然保留，每台设备最多保留最近 100 条。
- 没装 Everything 时，「找本机文件」里可以点「安装 Everything」运行官方安装向导；装了没开时可以点「启动 Everything」。
- 第一次进入「共享 → 传输」时可以一键放行防火墙，之后在「传输设置 → 防火墙」也能放行。
- 订阅的配置有新版本时，配置页顶部发布者名字旁会出现红点，点「更新」即可更新。
- 自动更新时如果旧版本卡在退出，新版本会在约 20 秒后自动结束它，不用再去任务管理器。
