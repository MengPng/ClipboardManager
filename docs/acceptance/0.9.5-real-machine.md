# 0.9.5 实机验收清单

适用版本：0.9.5（`0.9.5-everything-guide`，schema 8），只发布 EXE 与便携 ZIP。
自动测试与 LayoutCheck 不能代替下列项目。逐项在真实 Windows 上操作，记录结果（通过 / 失败 + 现象）、机器与日期。

准备：两台 Windows 10/11 x64 电脑 A、B，在同一局域网（同网段 Wi-Fi 或有线均可）；至少一台显示器缩放为 125% 或 150%；另备一台从未装过 Everything 的机器（虚拟机即可）。

## 1. 安装与应用内更新

| # | 操作 | 预期 | 结果 |
|---|------|------|------|
| 1.1 | 0.9.3 运行中，等待自动检查或在托盘点「检查更新」，选择更新到 0.9.5 | 下载并校验后自动重启为 0.9.5，设置、历史、收藏、设备 ID 保留 | |
| 1.2 | 0.9.4 开启「保持可被发现」后更新到 0.9.5 | 旧进程卡住时，新进程最多约 20 秒后结束它并正常启动；不出现两个托盘图标 | |
| 1.3 | 浏览器下载 0.9.5 EXE 首次运行 | 记录 SmartScreen 提示（未签名时会显示"未知发布者"）；签名后再测一次 | |
| 1.4 | 便携 ZIP 解压运行 | 可正常启动，恢复助手在同目录 | |
| 1.5 | 已签名构建：右键 EXE → 属性 → 数字签名 | 签名有效，带时间戳 | |

## 2. Everything 引导安装（ADR-0007 附录 A）

| # | 操作 | 预期 | 结果 |
|---|------|------|------|
| 2.1 | 无 Everything 的机器，选中文字按 Ctrl+Alt+F | 弹窗显示「未安装 Everything。」和「安装 Everything」按钮，不自动安装 | |
| 2.2 | 点「安装 Everything」 | 出现 UAC，确认后打开官方安装向导（中文/多语言），向导中的选项可自行选择 | |
| 2.3 | 完成向导 | 弹窗回到前台并自动重新搜索，出现结果；`%TEMP%\ClipboardManager\Everything` 下不残留安装程序 | |
| 2.4 | 在 UAC 处点「否」 | 弹窗仍在，显示「安装 Everything」，没有报错弹窗 | |
| 2.5 | 已安装但退出 Everything，再按 Ctrl+Alt+F | 显示「Everything 没有运行。」和「启动 Everything」；点击后 8 秒内恢复搜索 | |
| 2.6 | 设置 → 划词查找 → 搜索来源 | 三种状态文字正确，按钮分别为「安装 Everything」「启动 Everything」或不显示 | |
| 2.7 | 安装后检查 Everything 的设置 | 本程序没有改动 Everything 的任何设置 | |

## 3. 防火墙放行

| # | 操作 | 预期 | 结果 |
|---|------|------|------|
| 3.1 | 全新设置，第一次进入「共享 → 传输」 | 弹出「放行防火墙」确认框，只弹一次 | |
| 3.2 | 点「放行」并确认 UAC | 提示已放行；`wf.msc` 入站规则中有 `ClipboardManager Config Sync TCP/UDP`（端口 53318） | |
| 3.3 | 再次放行 | 不产生重复规则 | |
| 3.4 | UAC 点「否」 | 没有报错弹窗；「传输设置 → 防火墙」仍显示「放行」 | |
| 3.5 | 规则已存在时打开「传输设置」 | 显示「已放行」，不显示「放行」按钮；「复制命令」仍可用 | |
| 3.6 | 公司电脑或组策略禁止本地规则 | 提示没有放行成功，可改用复制命令 | |

## 4. 局域网匹配与传输（A ↔ B）

| # | 操作 | 预期 | 结果 |
|---|------|------|------|
| 4.1 | 两台都保持可被发现，在 B 输入 A 的匹配码 | 匹配成功，两边都出现对方卡片并显示「在线」 | |
| 4.2 | A 发送 2–3 GB 单个文件到 B | B 弹出接收确认；记录实际速度；落盘文件 SHA-256 与源一致 | |
| 4.3 | 传输中拔网线或断 Wi-Fi，恢复后重发同一文件 | 从断点续传，不重新询问（30 分钟内） | |
| 4.4 | 从资源管理器拖一个文件夹到设备卡片 | 打包为「文件夹名.zip」发送；B 解压后目录结构一致；A 的临时 zip 已删除 | |
| 4.5 | 设备页点「选择文件夹」选多个文件夹 | 每个文件夹各一个 zip | |
| 4.6 | 完成若干传输后退出并重启 A | 设备页仍列出已完成/失败的记录；「清除已完成」后重启不再出现 | |
| 4.7 | 删除已接收的文件后点该记录「打开位置」 | 提示文件已不存在，不崩溃 | |
| 4.8 | 历史页右键「发送给已匹配设备」发送文本 | B 收到 .txt；A 的临时文件已删除 | |
