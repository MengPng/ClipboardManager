# 0.7.6 本地计算器

## 使用

计算器位于个人配置后。输入 `1+1` 后按 Enter，或使用数字键面板，结果为 `2`。可复制数值、完整算式，或从最近记录复制原算式。最近记录仅在本次运行保留，最多 30 条；清空或删除记录不影响剪切板历史。

自动计算剪切板算式默认关闭。在计算器页勾选后立即保存到现有设置，重启后保留。新复制的 `1+1` 在后台处理完成后变成 `1+1=2`，目标软件正常 Ctrl+V 即可。开启前已有的剪切板内容不会补算，暂停监听和来源应用排除同样适用。

本工具的复制原算式通过自身写回标记避免立即再次改写。关闭自动计算后不再改写后续复制，已经生成的结果不会自动还原。

## 范围与精度

- 支持 `+ - * / × ÷ −`、小括号、负数和点号小数，使用 decimal 运算和 invariant 格式。
- 输入最多 512 字符、32 层括号/正负号嵌套、128 次二元运算；数字最多 29 位有效数字和 28 位小数。非整除结果受 decimal 精度限制。
- 不支持百分比、函数、指数、货币符号、多行或包含等号的内容。无效输入、除零和溢出不触发自动改写。
- 自动计算要求至少一个二元运算符，纯数字及 `yyyy-M-d` 形状的 ISO 日期保持原样。其他外观符合算式的编号仍可能被识别，因此仅在需要时开启。
- 复制后立刻粘贴可能发生在计算前，此时粘贴原算式。富文本算式改写后仅保留 Unicode 文本，目标应用是否接受文字由该软件决定。

## 职责与数据契约

Application 的 CalculatorService 负责有界解析和计算，不执行代码、不联网；ClipboardCalculationService 负责设置/隐私复核、防循环和完成事件。

Windows 消息钩子只投递来源及剪切板 sequence。后台消费者读取前后检查 sequence，先通过现有服务保存原历史，再对成功捕获的文本尝试自动计算。IClipboardTextRewriter 的 Windows 实现在有效 owner 下 OpenClipboard，在同一次锁定内比较 sequence 与原文，分配资源后替换。竞争采用现有有限重试，写回失败尝试在同一锁内恢复原文，错误日志不含正文。

开关使用 AppSettings.EnableClipboardCalculator，默认 false，复用原子设置保存和完整备份设置载荷；不改变 SQLite schema、Workspace、账号或同步契约。计算结果不直接进入同步或团队空间。

## 验证边界

自动测试覆盖计算精度、优先级、输入限制、开关、暂停/排除、防循环、条件写回拒绝和失败清理、设置重启。Windows 原生锁内条件写回、WPF 窄屏/不同 DPI 与任意目标软件真实 Ctrl+V 仍需实机验收；后台构建通过不能替代这些检查。
