## 结论

采用「青序」：以月白、黛色、天青、青黛建立现代桌面工具体系。传统色只提供色彩关系，不延续现有信笺纸材质，也不增加古风装饰。主页在既定紧凑窗口内使用单列记录流，把搜索、选择和再次使用放在同一条视觉动线上。

本轮只创建一个主页方向，不延续 `docs/design/2026-10-21-ui-upgrade/` 中已有的方案。保留实际功能、快捷键和 Local-first 数据边界，不增加虚假云端、团队或 AI 入口。

## 1. 选色

| 色彩 | 色值 | 用途 |
| --- | --- | --- |
| 月白 | `#EEF7F2` | 应用基底与左侧导航 |
| 瓷白（衍生中性色） | `#FAFCFB` | 搜索、列表与正文阅读面 |
| 黛色 | `#3B4F5C` | 正文与主要信息 |
| 青黛 | `#1A3A5F` | 标题、主按钮、键盘焦点 |
| 天青 | `#6C9BCA` | 选中边界、焦点环、当前状态；不作为浅底正文色 |
| 浅青（衍生色） | `#DCEAF2` | 当前记录背景 |
| 赭石 | `#862617` | 收藏标记等少量强调，不承担普通主操作 |

色名及色值来自用户提供的[中国传统配色资料库](https://colors.xiaoxiaodong.ai/index.html)；瓷白、浅青是为界面可读性补充的衍生中性色，不宣称为传统标准色。

对比度计算（WCAG 相对亮度公式）：黛色/月白 7.82:1，青黛/月白 10.59:1，白字/青黛 11.57:1，青黛/浅青 9.42:1。正文和主操作满足普通文本 4.5:1 的对比要求。最终仍以实际 WPF 渲染复核。

## 2. 布局

默认窗口严格保持 **340 × 540 DIP**，最小窗口严格保持 **340 × 450 DIP**。不使用宽屏三栏，不增加左侧常驻导航，不要求用户扩大窗口才能使用核心功能。

```text
┌────────────────────────────────────┐
│ 剪切板              监听  暂停  置顶  设置 │
│ 历史   配置   待办   计算   划词   │
│ 搜索正文或来源应用              ⌕ │
│ 全部       文本       图片    文件 │
│ 最近复制                           │
│ ┌────────────────────────────────┐ │
│ │ 本周产品检查清单          刚刚 │ │
│ │ 文本 · 记事本                  │ │
│ └────────────────────────────────┘ │
│   本地优先，让每一次复制…    3 分钟 │
│   文本 · 微信                      │
│   product-white-400.png    12 分钟 │
│   图片 · 资源管理器                │
│   发布检查记录.xlsx        28 分钟 │
│   文件 · Excel                     │
│ 本机保存 · 离线可用     Enter 使用 │
└────────────────────────────────────┘
```

- 首屏只突出一个主任务：找到内容并重新使用；不展示欢迎语、营销标题或统计卡片。
- 顶部主导航统一使用两个汉字：**历史、配置、待办、计算、划词**。不使用「个人待办」「个人收藏」等较长名称。
- 标题栏保留**常驻前台（全局窗口置顶）**开关，与暂停、设置并列；标题栏和五页导航在所有功能页固定显示，不随列表滚动或页签切换消失。窗口全局置顶与单条历史记录置顶是两项独立能力，不得合并或互相替代。
- 搜索、类型筛选与连续记录流构成主页；当前记录只用一个浅青选中面强调，不把每条记录做成悬浮卡片。
- 选中文本可就地展开完整正文，图片和文件通过详情浮层查看；详情不挤压记录列表，打开时管理焦点，`Esc` 先关闭详情再关闭面板。
- 底部仅保留必要状态和主要快捷键，操作细节留在选中项菜单，避免拥挤。
- 保留「配置」一级入口及其现有文件夹、导入导出和 Workspace 语义，不改名为「个人收藏」。历史记录的快速收藏状态与独立配置库不得混为一谈；「存入配置」仍进入用户明确选择的配置目录。
- 340×450 DIP 下减少可见记录数量，不缩小正文字号、不裁掉导航与主操作；列表自然滚动，搜索和筛选不换行溢出。
- 保留紧凑/宽松列表密度；图片只加载缩略图，大预览按需加载并释放。

## 3. 视觉与交互

- 字体：优先 `Microsoft YaHei UI` 处理中文，数字与快捷键使用 `Cascadia Mono`。标题 14px、正文 13px、辅助信息 11–12px；不依赖字体下载。
- 形状：面板圆角 10px，输入框和选中面 6px，普通按钮 5px；记录行不是独立卡片，不堆叠阴影。
- 分隔：以留白、对齐和细分隔线建立层级，只给当前记录使用浅青底。
- 图标：沿用 Windows Fluent 图标语义，实施时改为清晰的矢量/字体资源，不引入 Emoji。
- 搜索：输入时保留当前选择，结果返回后再更新预览；过期搜索不得覆盖新结果。
- 选择：120ms 浅青面与左侧天青标记过渡；方向键移动立即响应，动画不得阻塞输入。
- 复用：`Enter` 写回后，主按钮短促显示「已复制」并保留明确焦点；自动粘贴仍须按既有契约独立判断，不把复制成功当作目标应用已接收。
- 面板：打开 160ms、关闭 100ms，位移 6–8px；无回弹、无循环背景动效。
- 详情：文本、图片和文件使用同一预览区域，但内容切换不大幅改变窗口尺寸。
- 删除：先隐藏记录并给可撤销提示；软删除和 Workspace 规则不变。
- 可访问性：可见键盘焦点、完整无鼠标路径、输入框快捷键隔离；遵循 Windows 减少动画设置。

动效参考提炼自 [Motion Design Skill](https://github.com/LottieFiles/motion-design-skill)、[Motion AI Kit](https://github.com/motiondivision/ai-kit)、[MotionVideo](https://motionvideo.xyz/) 与 [Bencho](https://bencho.dev/)：只让动画表达状态、空间关系与操作反馈，不照搬网页特效。

## 4. 可行性评估

结论：适合在现有 WPF/.NET 8 技术基线上实施，不需要换前端框架或引入动画依赖。

| 范围 | 实施方式 | 评估 |
| --- | --- | --- |
| 色彩、字体、间距、控件状态 | 重建主题资源与控件模板，保持资源集中 | 低风险 |
| 单列主页与按需详情 | 调整 `MainWindow` 结构，复用现有记录 ViewModel；文本就地展开，图片/文件使用详情浮层 | 中风险，主要工作量 |
| 待办、收藏、计算、划词 | 保留既有面板与服务，迁入新的导航容器 | 中风险，需逐页适配宽度 |
| 列表与图片性能 | 继续虚拟化；预览与缩略图分离，离屏释放位图 | 中风险，需真实大数据验证 |
| 选择、复制、展开反馈 | WPF `RenderTransform`、透明度和短动画；不逐帧布局 | 低至中风险 |
| 剪切板与隐私链路 | 不改监听、哈希、写回、排除、自动粘贴核心逻辑 | 必须保持不变 |

第一阶段建议只交付新主页、主题基础、键盘与按需详情；其余四个功能页第二批迁移，避免一次性改动所有业务面板。正式验收需要实际 EXE 检查 340×540、340×450、更大窗口、不同 DPI、多显示器、键盘焦点、长文本、损坏图片和失效文件。静态预览不能替代这些验收。
