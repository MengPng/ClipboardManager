# 计算页重新设计（页面 + 逻辑）

效果图：`calculator-mock.png`（标准主题；HTML 示意，落地以真实 WPF 渲染为准。页签按"划词已移除"画成四个）。

## 现状问题（读代码确认）
页面（`MainWindow.xaml` CalculatorPanel、`MainWindow.Calculator.cs`）
1. 单列滚动：自动计算勾选框 + 说明文字 + 输入框 + 结果框 + 三个按钮 + 4×6 共 24 键键盘，历史记录被挤到首屏之外；"="、"计算"按钮、Enter 三处重复。
2. 必须按 Enter / "计算"才出结果，没有实时反馈；结果框只读，要再点按钮才能复制。
3. 每条记录 4 个按钮（复用/复制原算式/复制结果/删除），一行占三行高。

逻辑（`CalculatorService`、`ClipboardCalculationService`）
4. 解析器只认半角数字、`+ - × ÷ * / − ( )`。常见复制内容会直接失败：`1,250`（千分位）、`¥1,299`、全角 `（１＋２）`、`x` 当乘号、`50%`、`2(3+4)`。
5. 结果用 `G29` 原样输出：`1/3` 得到 28 位小数，没有千分位显示，也没有"精确/近似"提示。
6. 自动计算会**改写剪切板**（`1+1` → `1+1=2`）。只排除了 `yyyy-m-d` 日期；`10-12`、`5-3`、`2026-10` 这类页码/房号/年月会被静默改写成 `10-12=-2`，原内容丢失。
7. 错误信息一律弹在输入下方，输入到一半就报错；错误文案末尾有多余空格。

## 新页面（自上而下，340×540 内）
- 顶部一行：`剪切板里的算式：[关闭 | 仅提示结果 | 直接改写]` 下拉，替换勾选框和说明段落。右侧显示纸带条数。
- 纸带（最近计算，本次运行，最多 30 条，仅内存）：每行左算式（次要色）右结果（加粗，等宽数字）；悬停/选中才显示 复制 / 复用 / 删除。点行 = 复用。一行一线，不再三行高。
- 当前输入：单行输入框（20px，等宽数字），右侧 ⌫ 与键盘开关；下方"实时结果"行：`= 1,375`，旁边灰字显示展开后的算式（如 `1250 + 125`，用于解释百分号），右侧主按钮"复制结果"。
- 小键盘默认收起（记住上次状态），展开为 4×5：`清空 ⌫ % ÷ / 7 8 9 × / 4 5 6 − / 1 2 3 + / ( ) 0 . =`；"( )"键插入一对括号并把光标放在中间；`=` 同 Enter。键高 34px。
- 页脚提示：`Enter 记录并继续 · Ctrl+Enter 复制结果`（沿用现有页脚计数位置）。
- 键盘操作：Enter = 记录到纸带并把结果放回输入框（全选）；随后键入运算符则接着算，键入数字则重新开始；Ctrl+Enter = 复制结果并记录；Esc 清空；↑ 调出上一条算式。

## 新逻辑
解析前先**规范化**（只在 `CalculatorService` 这一个边界做一次，内部都用规范串）：
- 全角数字/运算符/括号/句点 → 半角；`x`、`X`、`*` → `×`；`/` → `÷`；`–`、`—`、`−` → `-`；中文逗号不当千分位。
- 千分位：仅当整段匹配 `\d{1,3}(,\d{3})+(\.\d+)?` 时去掉逗号；其他位置的逗号视为错误。
- 前导货币符号 `¥ ￥ $ € £` 去掉（只在数字前）。
- 末尾的 `=` 忽略（兼容 `1+1=` 粘贴）。
语法：
- 新增后缀 `%`：单独的 `y%` = y/100；`x + y%`、`x - y%` = x ± x·y/100；`x × y%`、`x ÷ y%` = x × (y/100) 等（用 y/100）。
- 新增隐式乘法：`2(3+4)`、`(1+2)(3+4)`、`2 3` 不允许。
- 新增 `^` 乘方（右结合，指数为整数且 |指数| ≤ 64，否则报错）。
- 仍用 `decimal`；限制不变（512 字符、嵌套 32、128 次运算、28/29 位）。不做函数（sqrt/sin 等需要 double 和新的精度规则，本版不做）。
显示：
- 结果最多保留 12 位小数，去尾零；发生舍入时在结果后加"≈"并在悬停提示里给出完整值；整数部分显示千分位。
- **复制出去的是不带千分位的纯数字**（便于粘进 Excel）；"复制算式与结果"沿用 `算式=结果`。
错误：
- 区分三类：**不完整**（输入中，如 `1+`、`(2`）→ 不显示错误，结果行灰显"…"；**非法字符/格式** → 结果行显示简短原因；**除数为 0/溢出** → 显示具体原因。仅在 Enter 时才弹出强调色错误。

## 剪切板算式识别（行为变更，需在 CHANGELOG 写明）
- 设置项 `EnableClipboardCalculator`（bool）改为三态 `ClipboardCalculatorMode`：`Off` / `Hint`（新默认）/ `Rewrite`（旧行为）。旧设置里 `true` → `Rewrite`（保持老用户行为不变），`false` → `Off`；全新安装默认 `Hint`。
- `Hint`：**不改写剪切板**。历史页中，文本为短单行（≤ 64 字符）、含数字且含至少一个二元运算符、通过计算的行，在行尾显示 `= 结果` 小标签（显示时计算，不入库）；选中该行时 Ctrl+Shift+C 或右键"复制计算结果"复制结果，Enter 仍粘贴原文。
- `Rewrite` 沿用 `ClipboardCalculationService`，并补两条防误判：纯 `数字-数字`（如 `10-12`）、`年-月`（如 `2026-10`）不自动改写。
- 这是最重要的逻辑调整：默认不再静默改写用户的剪切板。

## 不做 / 边界
- 不做科学函数、进制、单位换算、汇率；不持久化纸带（隐私，仍仅本次运行）；不改计算以外页面的行为。
- 主题：只引用主题 token，不写死颜色，三套主题都要能用（标准 / 夹夹 / Kami）。

## 验收
1. 单元测试（`tests`）：规范化（全角、千分位、货币、`x`、末尾 `=`）、百分号四种语义、隐式乘法、乘方边界、12 位小数舍入与"≈"、不完整 vs 错误分类、限制项；`10-12`/`2026-10` 在 Rewrite 下不改写；设置迁移（旧 bool → 三态）。
2. LayoutCheck 增加计算页渲染（小键盘收起/展开）与 340×450 最小尺寸无裁切；历史页算式标签渲染。
3. 实机：键盘全流程（输入、Enter 链式计算、Ctrl+Enter、↑、Esc）；小键盘开关状态记忆；三套主题；Hint 模式下复制 `(1250+380)/3` 后历史行出现 `= 543.33` 且剪切板原文不变。
4. 未实机验证的项不得在文档里写成"已验证"。
