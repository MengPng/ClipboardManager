# 主页方案 v5

日期：2026-10-21
状态：待审阅的静态预览，尚未修改产品界面。

## 约束

- 默认窗口 340×540 DIP，最小 340×450 DIP。
- 不延续信笺、纸纹、泛黄底色。
- 列表不显示缩略图、类型图标盒和来源应用。
- 复制操作不使用全宽横幅。

## 重新学习后的判断

- huashu-design：先有概念再执行；装饰性图标和容器是噪声，“删掉会变差吗”是筛选标准。
- 传统色参考：只取一个强调色形成识别度，采用花青 `#1661AB`，其余为中性灰。
- Bencho：反馈应出现在动作发生处，而非空间远处。
- Anatomy、Hairline：视觉变化必须对应真实状态，细线表示结构而非装饰。
- LottieFiles、Motion：高频工具选用克制动效；只动 transform/opacity，可打断，尊重减少动画。

## 概念

“选中即工作台”：普通记录只是一行文字；只有当前选中项展开为可操作区域，复制、收藏、置顶记录就在内容旁边。没有常驻底部大按钮，视线不在内容与操作之间来回跳。

## 结构

1. 标题栏：品牌、监听状态胶囊、暂停 / 窗口置顶 / 设置 / 收起。
2. 分段导航：历史、待办、配置、计算、划词五等分，白色滑块表示当前。
3. 搜索。
4. 类型下划线筛选，右侧置顶条件。
5. 日期分组和条数。
6. 列表：选中项为展开工作台，其余为标题 + 预览 + 时间。
7. 底部键盘提示。

## 交互

- Up/Down 切换选中项，选中项展开、旧项收起（140 ms，标准缓动）。
- Enter 与“复制”按钮等效，继续写回剪切板并隐藏窗口。
- Ctrl+Enter 仍为尝试粘贴，失败保留剪切板并提示。
- Space 打开完整预览；搜索框内 Space 正常输入。
- 收藏 / 置顶图标按下 120 ms 状态变化，以写入成功为准。
- 新捕获内容不抢选中和滚动位置。
