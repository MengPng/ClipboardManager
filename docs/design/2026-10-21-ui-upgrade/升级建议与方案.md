# 界面与交互升级建议

日期：2026-10-21  
状态：旧方向已被用户明确否定，仅保留研究记录。当前以《产品美学方案-v2.md》与 `homepage-product-v2.png` 为准；未修改产品界面或行为。

## 推荐方向

采用“纸白墨青”：从现有蓝墨信笺延续纸张、墨色和细线的识别感，重新组织导航、搜索、内容层级与操作反馈。传统色用于建立配色关系，实际界面颜色按可读性调配，不把自定义颜色冒充为色谱中的标准色。

产品的主要任务是“呼出 → 查找 → 确认内容 → 复制并返回工作”。主页围绕这个流程安排空间。收藏、待办、计算和划词继续可直接到达，但不在历史页同时展示各自的内容。

## 主页与导航

### 默认工作尺寸

推荐把 440×720 DIP 作为舒适尺寸，340 DIP 继续作为重要的紧凑使用场景。预览图展示舒适尺寸，不能据此认定紧凑布局已经通过。

左侧约 60 DIP 功能导航：

- 历史：最近捕获内容。
- 收藏：现有个人配置中的文件夹及内容。仅在数据语义核对后更名，不改变 Workspace 或数据位置。
- 待办：保留本地待办及自定义标签。
- 计算、划词：工具区域，保持一次点击到达。
- 设置：侧栏底部。

340 DIP 场景应减少页头留白、使用单栏内容与紧凑行高；不要把 440 DIP 画面直接缩小。若 60 DIP 侧栏导致正文过窄，收窄到仅图标导航，并保留 tooltip、自动化名称与键盘入口。最终采用哪种方案应通过真实 WPF 布局点验决定。

### 历史页层级

1. 页头只说明当前任务及本地状态。
2. 搜索位于列表上方，提示“搜索内容或来源应用”，保留 Ctrl+F。
3. 类型过滤保留全部、文本、图片、文件；置顶作为状态筛选，明确其与类型的组合规则。
4. 列表通过类型图标、正文或文件名、来源和时间形成层级。正文原样保存，预览处理仍遵守领域规则。
5. 选中行使用淡墨青背景；鼠标悬停与键盘选中明确区分。功能不只依赖颜色。
6. 主操作在底部固定：“复制并收起”。全局 Enter 仍为写回剪切板并隐藏；Ctrl+Enter 明示“尝试粘贴”。

日期分组属于建议，实施时先检查分页与虚拟化方式，避免因分组破坏性能。预览中的日期和来源不代表新增数据采集。

## 交互建议

| 场景 | 建议行为 | 必须保留的约束 |
| --- | --- | --- |
| 呼出 | 立即呈现可用搜索与当前选中项 | 不等待动画；保留呼出前目标窗口 |
| 单击记录 | 默认选中，便于确认正文；如存在用户配置的单击使用模式则保留并明确设置 | 不静默覆盖现有使用习惯 |
| 使用记录 | Enter 或明确按钮复制并收起；双击遵从既有可配置行为 | 输入框编辑不能误触使用 |
| 长文本与大图 | 建议 Space 打开预览；图片默认使用缩略图 | 输入框中的 Space 必须正常输入；预览开关不写入剪切板 |
| 收藏与置顶 | 选中或悬停后显示辅助动作，键盘聚焦时同样可见 | 收藏创建快照；置顶不等于收藏 |
| 新内容到达 | 用户正在浏览旧记录时，不抢走选择和滚动位置；可用轻提示回到最新 | 捕获继续正常进行 |
| 删除 | 普通历史删除考虑提供短时间撤销；批量和危险操作展示范围并确认 | 撤销必须经过服务与仓储，不能用 UI 假恢复 |
| 暂停 | 直接显示手动或剩余时长，操作后状态由监听器确认 | 暂停与排除必须在载荷读取前生效 |
| 错误 | 原位显示原因与可执行的重试，保留可恢复内容 | 不吞异常、不显示正文或密钥 |
| 自动粘贴 | 发送失败提示“内容已复制，请手动粘贴” | 不把发键成功当成目标应用接收成功 |

“Space 预览”、新内容提示与撤销是拟新增能力，不是对已有功能的完成声明。实现第一版时优先做预览和稳定选择；删除撤销可后续独立加入，避免在首轮视觉升级中扩大仓储改动。

## 其他页面统一方式

- 收藏：文件夹列表与内容列表清晰分开；新增、移动、重命名有明确入口。非空文件夹默认移到未分类，拖动与菜单移动都可用。
- 待办：标题、状态、用户标签为主，完成统计次要；新增输入位置稳定。完成动作不触发整页跳动；标签不自动创建。
- 计算：保留“结果优先、算式其次、细线分隔”的已有原则，不重新装饰成多层卡片。
- 划词：模板、开关和 Provider 配置分组，继续采用显式动作触发请求，默认设置不在视觉改版中改变。
- 设置：统一字体、间距、焦点、错误提示与保存反馈；账号、云端等未启用能力不因改版出现假入口。

## 视觉规范草案

| 用途 | 建议值 |
| --- | --- |
| 纸面 | #F8F7F2，细微稳定纹理 |
| 主文字 | #25333D |
| 主操作 / 焦点 | #28516A |
| 选中底色 | #E4EEEC |
| 次文字 | #65727A |
| 分隔线 | #DDDFD8 |
| 听取状态 | #48795E |
| 字号 | 正文 13–14 DIP，重要内容 14 DIP，辅助 11–12 DIP |
| 圆角 | 4–6 DIP，不给每行套卡片 |
| 间距 | 4 DIP 基础步进，常用 8 / 12 / 16 |

延续 Windows 中文可读字体和现有应用图标；品牌标题可以略增强字重，列表保持阅读字体。传统美感从配色、留白、细线和秩序产生，不使用毛笔字替代正文。

## 动效草案

以下时间为本产品的设计建议，不是外部资料的精确复刻或已测性能值。

| 动作 | 建议时间 | 视觉变化 |
| --- | --- | --- |
| 悬停 / 按压 | 80–100 ms | 背景或墨色变化，不移动列表 |
| 呼出 | 120–160 ms | 淡入与不超过 4 DIP 的位移 |
| 导航 / 筛选 | 120–160 ms | 当前标记切换，内容不整页飞入 |
| 预览展开 | 160–200 ms | 内容淡入；可立刻关闭 |
| 收藏 / 完成 | 120–180 ms | 图标状态改变，反馈来自真实写入结果 |
| 复制失败 | 即时 | 明确文字反馈，不用抖动代替错误原因 |

WPF 优先采用 RenderTransform 与 Opacity 等适合的呈现属性；避开逐帧调整大列表布局尺寸。系统关闭动画时直接显示终态；重复呼出、快速输入和切换应能中断前一个过渡，动画不阻塞键盘。

## 确认后的第一版范围

1. 集中更新主题、字号、间距、图标和焦点样式。
2. 调整导航与历史页结构，保留原服务和数据契约。
3. 明确选中、复制、收起与粘贴尝试的行为，核对旧设置兼容。
4. 增加内容预览和必要状态反馈；对其他页面做同一套视觉规范适配。
5. 只添加服务真实支持的入口；新增行为单独测试。

建议首版不同时更改数据库结构、云端流程、账号或附件归属。若实现发现预览或安全状态需要架构调整，应先形成具体决策记录。
