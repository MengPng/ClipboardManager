# 产品美学方案 v2

日期：2026-10-21  
状态：静态设计稿，等待审阅，尚未实施。

## 本次修正

用户明确不希望延续信笺质感，并提供 Payvora 产品界面截图作为新的视觉参考。该要求替代旧版“纸白墨青”的方向；旧稿保留作记录，不再作为实施依据。

目标是让界面具备成熟产品的比例、层级、组件状态与操作秩序。取消纸纹、泛黄表面和文具隐喻，不把“产品美学”仅理解成换白色背景。

## 从参考中采用什么

- 中性灰底与白色内容表面，通过轻边界和留白分区。
- 深色选中导航和主按钮，蓝色用于选择与关键状态。
- 组件按职责使用不同尺寸和圆角：大内容容器、紧凑筛选、圆形工具按钮彼此有层级。
- 全局导航、页面任务、局部操作三层分开。
- 内容有足够密度，阅读仍然轻松。

参考中的财务指标、图表、头像、AI 推荐等与剪切板主要任务无关，不迁入本产品。当前图中的“产品界面参考.png”缩略图使用用户提供图片的本地缩略版本，仅为虚构历史列表的设计内容，未上传至外部服务。

## 主页结构

默认主页以 `340×540 DIP` 设计，最小尺寸为 `340×450 DIP`。`homepage-compact-v3.png` 是本轮默认主页预览，输出为 680×1080 像素，窗口本体严格按 340×540 DIP 绘制。

顶部：应用标识、历史 / 收藏 / 待办 / 计算 / 划词导航、暂停 / 窗口置顶 / 设置 / 收起。

第二层：历史记录标题与监听状态；右侧全局搜索。

第三层：类型筛选与置顶条件。

主体：单列历史列表。选中项以浅蓝底色表示，正文预览保持紧凑；完整内容由 `Space` 触发原位展开或独立轻量预览层，不在默认窗口硬塞双栏。

底部：本地状态、自动粘贴状态和常用键盘提示。

“收藏”暂为设计命名。正式实现前须核对现有个人配置语义，不能通过改名丢掉其配置能力或 Workspace 隔离。

## 紧凑与展开的关系

不能把大窗口直接设为 Alt+V 的默认弹出面板。此前的 `homepage-product-v2.png` 仅保留为展开模式概念，不是默认主页。

- 快速呼出：单列、搜索靠上、紧凑记录行，适合微信旁使用；默认严格遵循 340×540 DIP，最小严格遵循 340×450 DIP。
- 展开：列表和预览并排，适合长文本、图片、文件确认以及整理内容。
- 两种形态共享同一数据、选中项、筛选和动作；切换时保留搜索与滚动位置。
- 紧凑模式的完整正文通过预览层呈现。关闭预览回到原记录。

本轮已画默认紧凑主页；340×450 DIP 最小态仍需单独绘制或在真实 WPF 中点验。

字体使用适合 Windows 中文阅读的清晰字形，通过字号、字重和行距建立秩序。保留现有品牌图标，图标本身的后续升级应作为独立设计工作，不在本轮擅自替换。

主按钮与选中导航使用深色；蓝色有选择地用于选中行和类型提示。状态同时提供图形或文字，避免单独靠颜色表达。

## 交互与动效方向

- 单击选择，右侧随选中内容更新；是否单击即使用须兼容既有设置。
- 输入搜索时不移焦，更新结果时不播放逐行飞入动画。
- 已在列表中浏览时，新捕获记录不抢选中或滚动位置。
- “仅复制”保留窗口，“复制并收起”返回原工作。
- Ctrl+Enter 仍为尝试粘贴，失败保留剪切板并提示手动操作。
- 收藏、记录置顶、窗口置顶三者在工具提示和焦点说明中明确区分。
- 辅助按钮在悬停或键盘聚焦时可见，不能留不可见焦点。
- 动效建议：悬停 80–100 ms，选中和内容切换 120–160 ms，预览展开 160–200 ms。快速操作可打断，减少动画设置下直接终态。
- 动效用于解释当前操作和结果，不持续呼吸、不装饰性闪烁、不等待动画完成才允许输入。

4. 点验不同尺寸、DPI、键盘焦点、复制恢复和真实目标粘贴。

## v4 收束调整

用户进一步指出 v3 的框、文字和底部主操作彼此割裂，且列表中的缩略图、来源行、复制动作标签占比不合理。`homepage-compact-v4.png` 据此调整为当前审阅版本：

- 移除所有历史行缩略图和来源行；保留内容标题、单行预览和右对齐时间。
- 历史区域保持连续表面，只有当前选中项使用低饱和蓝色背景和细蓝线标记。
- 移除全宽深色“复制并收起”横幅；改为底部右侧的紧凑“复制”动作，仍提示 Enter。
- 选中数量、键盘提示和本地状态降为辅助信息，不与正文竞争。

v4 仍严格按 340×540 DIP 绘制，仍是静态稿。`复制`在实现中必须继续执行现有“写回剪切板并隐藏窗口”的语义；本稿仅压缩可见文案，不改变既有行为契约。
