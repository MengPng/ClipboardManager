# ADR 0004：本地划词入口与显式 AI 请求

- 日期：2026-10-21
- 状态：已实现，真实模型与多显示器兼容性待验收

## 决策

在现有本地剪切板功能之外提供可选的划词 AI 工具。这是用户明确要求的范围扩展，替代旧路线图中“当前不实现 AI”对本能力的限制；不引入账号、历史自动上传、OCR 或同步行为。

Windows 层负责选区手势、独立热键、临时复制、操作条和结果窗口；Application 层负责模板展开、显式操作后的发送与纯文本转换；Domain 定义模板、配置和 Provider 契约；Infrastructure 负责 HTTP 和既有凭据管理器适配。无数据库迁移。

结果窗口仅展示转换后的模型正文，高度随内容增长并限制在显示器工作区内，超长内容通过文本框滚动查看。模型请求增加纯文本指令，Application 再使用 Markdig 1.3.2 的纯文本渲染清除 Markdown 格式，避免模型未遵循指令时泄漏格式标记。采用成熟解析器处理嵌套强调、代码、链接、表格等，避免自行维护脆弱的正则组合；该版本提供 net8.0 目标且无额外运行时依赖，采用 BSD-2-Clause 许可证。许可证保存在 THIRD-PARTY-NOTICES.txt，嵌入 Application 程序集并随单文件发布复制。

配置和模板沿用原子保存的 AppSettings。旧设置缺少 selectionAi 时使用默认配置，快捷键与浮窗均关闭。提示词 UUID 和列表顺序随本地备份恢复；API Key 不进入备份。凭据按 Provider 与 Base URL 绑定，更换地址不自动迁移密钥。

2026-10-21 按用户界面定位要求，划词配置从通用设置弹窗移至主窗口顶部导航的“划词”页签（计算右侧）。该页复用同一设置编辑控件和既有原子保存、凭据保存与 `SelectionAiController.ReloadAsync` 路径，不复制状态或创建第二份设置；保留原弹窗类仅作为非主入口调用方的兼容包装。

模型请求使用非流式 Chat Completions，最长 60 秒、结果最大 2 MiB，不自动重试、不跟随 HTTP 重定向。2026-10-21 按用户后续明确要求，替代最初的二次确认流程：点击操作条中的提示词按钮即授权发送该次所选文字，结果窗口首次加载立即发送一次，不展示原文或展开后的提示词；仅采集选区和显示操作条不调用 Provider。窗口重复加载不重复发送，关闭窗口取消请求，失败可手动重试。错误不输出服务商响应正文或原始网络异常，以免回显输入或密钥。2026-10-21 读取 DeepSeek 官方首页，默认 endpoint 为 https://api.deepseek.com/chat/completions，模型为 deepseek-flash；模型名可由用户修改。2026-10-21 增加本地 AI 网关模式：仅允许 loopback 的 HTTP/HTTPS OpenAI 兼容地址，普通远端兼容接口仍只接受 HTTPS。

## 剪切板契约

在读取任何剪切板载荷前检查暂停和应用排除；等用户释放修饰键后再发送完整的 Ctrl+C 输入事件，x64 INPUT 为 40 字节。不抢回焦点，不向管理员进程提升权限。

预先复制支持的剪切板内存与 GDI 资源。DIB 像素优先于可由 Windows 合成的 CF_BITMAP，避免复制失效的合成句柄；无法安全保存的特殊格式在发键之前拒绝。读取最多等待约 1 秒，竞争采用有限重试。

监听器共享 SelectionClipboardGate，只抑制已识别的临时序列与本工具恢复序列；不暂停整个监听、不按时间窗口忽略其他应用。恢复在同一原生剪切板锁内核对版本，版本已变则保留新内容。失败不发送模型请求。来源仅提供进程级归因，不能区分同进程内的用户并发复制；超时后迟到的第三方复制也无法可靠归因，这类控件需单独验证。

浮窗仅由鼠标拖选/双击候选手势触发，不是 Windows 通用选区 API；某些软件无选区时仍会把整行复制出来，不能保证所有软件都有相同语义。功能默认关闭，用户可只启用快捷键。操作条无标题、无原文预览、无关闭操作，固定高度 34px，只呈现提示词动作；选择动作打开结果窗口并自动发送一次。管理员、远程会话和复制受限应用保留兼容性边界。

操作条显示期间，低层鼠标钩子向 UI 线程报告左键按下位置。若位置不在操作条的原生屏幕矩形内，控制器立即关闭操作条；条内点击保持事件传递给相应操作按钮。即使仅启用快捷键也启动该轻量监听以支持空白点击取消，但只有“自动浮动操作条”开关开启时，拖选/双击手势才会创建新的操作条。

这里的 34px 使用 WPF 逻辑像素（DIP），Windows 缩放时随界面缩放。本地网关采用与远端相同的 Chat Completions 请求；仅允许回环地址使用 HTTP。本地免鉴权网关未保存密钥时省略 Authorization，保存密钥后发送 Bearer；远端模式仍必须配置密钥。

## 验证与交付

单元测试覆盖展开、发送、取消、配置兼容与顺序、密钥隔离、请求形状和错误映射。`DesktopProbe --selection` 使用隔离数据目录和独立 WPF 目标，校验真实读出、文本/HTML/图片/多文件恢复、历史隔离、冲突与隐私策略、快捷键与鼠标浮窗；测试最后恢复进入探针前的剪切板。外部应用期间主动更改的内容优先保留。`--selection-ui` 不读取剪切板，独立验证结果窗口自动请求、只展示结果及关闭取消；`--selection-gateway` 仅用合成文本验证当前 Magpie 接入地址的真实请求。

界面复用当前主题资源，不改动主面板结构。正式版本的打包、签名、安装升级、真实 API 额度调用、多显示器与不同 DPI 均不能由这些测试替代。
