# ADR 0007：划词查找本地文件

日期：2026-11-05　状态：客户端已实现（0.9.1），未经真实聊天软件桌面验收

## 背景

在微信、企业微信等聊天窗口里，对方经常发来"把报价单V3.xlsx 发我一下"之类的消息。用户需要选中文件名，马上在本机找到这个文件，再复制文件发回去，或者复制它的路径。本机已装有 Everything 这类索引工具，问题是从"选中文字"到"复制文件"要切换好几次窗口。

0.8.7 移除划词 AI 时，AGENTS.md 规定：未经新的架构决策，不得重新引入全局鼠标钩子、模拟按键取词或自动调用模型接口。本 ADR 就是这份决策。它的范围只到"本地查找文件"，划词 AI 不会因此恢复。

## 决策

1. **只在用户明确要求时读取选区**。默认入口是全局快捷键 **Ctrl+Alt+F**（设置 → 划词查找，可改可关；默认开启）。按下之前不读取、不缓存任何选中内容。
2. **取词顺序**：
   - 先用 UI Automation 的 `TextPattern.GetSelection()`，限时 700 ms。这条路不碰剪切板。
   - 读不到时退回模拟 Ctrl+C，前提是以下检查全部通过：快捷键修饰键已松开；目标窗口仍在前台；剪切板现有内容的来源不在排除列表里。现有内容没有所有者窗口时可以快照：这时无人能被要求延迟渲染，数据早已在剪切板里，快照只在内存中保留到恢复为止。有所有者窗口但认不出进程时，只要配置了排除项就拒绝。
   - Ctrl+C 之前先完整快照剪切板（所有格式），读完立即恢复。这期间产生的剪切板序号由 `SelectionClipboardGate` 交给 `SelfWriteSequenceGate`，不进入历史。
   - 快照或恢复失败时放弃本次操作并提示，不留下半截剪切板。
   - `SendInput` 只有返回值等于事件总数才算发送成功，与自动粘贴契约一致。
3. **拒绝的场景**：
   - 前台是控制台或终端：Ctrl+C 会中断程序，提示手动复制。
   - 监听已暂停，或来源进程在应用排除列表中：在读取任何载荷之前就拒绝。
   - 选区超过 4000 字符。
   - 前台是本程序自己。
4. **可选浮动按钮**（默认关闭）：
   - 打开后安装 `WH_MOUSE_LL` 低级鼠标钩子。钩子只判断"拖选或双击结束"这个手势，不读取任何内容。
   - 只有前台进程在白名单里（默认 Weixin、WeChat、WXWork、QQ、DingTalk、Feishu、Lark，可编辑）时，才在光标旁显示「🔍 找文件」。
   - 按钮窗口带 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`，不抢焦点，聊天窗口的选区保持不变；4 秒后自动隐藏。
   - 点击按钮时才走第 2 条的取词流程。
   - 关闭开关或白名单为空时，钩子立即卸载。
5. **解析**（`Application/Services/FileSearch/FileSearchQuery`，纯函数，带单元测试）：
   - 绝对路径或 UNC 路径：直接定位。不存在时退回按文件名搜索。
   - 带扩展名的文件名：转成 `"stem" *.ext`。
   - 其余视为关键词：逐个加引号，使 Everything 的运算符按字面处理；最多 6 个。
   - 长段落直接拒绝。
   - 排序（`FileSearchRanker`）规则：
     - 完全同名优先，其次带编号的副本，再次是子串匹配；同等匹配下按修改时间排序；
     - 隐藏回收站中的结果；
     - 降低 `node_modules` 等噪声目录的排名；
     - 去重，最多 20 条。
6. **索引只走 Everything IPC**（`WM_COPYDATA` + `EVERYTHING_IPC_QUERY2W`，在独立 STA 线程上进行，超时 3 秒）。默认实例找不到时，尝试已知的命名实例。Everything 未运行时：
   - 设置页如实显示"未检测到 Everything"；
   - 搜索窗口给出可读提示。
   不扫描磁盘，不自建索引，不调用 Everything 以外的程序；Listary 暂不集成（没有公开的查询接口）。
7. **结果窗口**：
   - Enter 把文件写入剪切板（`CF_HDROP`，与「文件」历史使用同一写回路径和防循环标记）；
   - Ctrl+C 复制路径；
   - Shift+Enter 在资源管理器中定位；
   - 双击结果或 Ctrl+Enter 用默认应用打开（文件夹在资源管理器中打开；没有关联程序时交给系统"打开方式"；可执行类扩展名沿用 `ConfigSyncPolicy.IsHighRiskFile`，打开前单独确认，默认按钮为"否"）；（0.9.2 补充）
   - Esc 关闭。
   复制类操作关闭后焦点交还给原窗口，用户在聊天框里直接粘贴即可；打开文件时焦点交给被打开的应用。不自动粘贴，也不自动发送。
8. **隐私**：
   - 不联网，不调用任何模型。
   - 选中的文字不入库、不入同步 Outbox。
   - 日志只记录异常类型，不记录选中文字、查询词或结果路径。
9. **设置窗口重做**（同版本）：
   - 左侧导航分为常规、外观、记录与存储、隐私、划词查找、备份与恢复、关于七页。
   - 每个字段在改动时单独提交，提交串行执行。每次提交的步骤：读取最新设置 → 修改 → 校验 → 需要时重新注册快捷键 → 原子保存；失败时回滚并显示原因。
   - 删除"保存/取消"按钮。

## 不做的事

- 不恢复划词 AI、提示词或模型调用；不对选区做翻译、摘要。
- 不在白名单之外的应用显示浮动按钮；不默认开启鼠标钩子。
- 不自动发送文件或自动粘贴到聊天窗口。
- 不随包分发 Everything，也不代替用户安装或启动它。

## 风险与待验收

- 微信 4.x、企业微信的聊天气泡多为自绘控件，UIA 很可能读不到，这时会走 Ctrl+C 回退。回退路径在这些应用里的真实表现待实机验证。
- 部分应用会拦截模拟按键，或者以管理员权限运行（UIPI 限制），这时取词会失败并提示手动复制。
- 浮动按钮"不抢焦点、不丢选区"，以及低级鼠标钩子对系统输入延迟的影响，都待实机验证。
- 多显示器与 100%/125%/150% 缩放下的按钮和弹窗位置待验证。
- 没有 Everything 的机器上只能看到提示，不提供替代搜索。
