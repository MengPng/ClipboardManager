# ADR 0003：腾讯云账号与配置同步边界

- 状态：已接受，Phase 5 正式环境实施中
- 日期：2026-09-09

## 决策

云端实现由供应商无关的 Domain/Application 契约与腾讯云 Infrastructure Provider 组成。服务端使用 ASP.NET Core 8 API，部署到腾讯云 Lighthouse、CVM 或容器服务；数据使用 TencentDB for PostgreSQL，附件使用私有 COS。客户端不持有腾讯云 SecretId/SecretKey，附件上传下载只使用服务端签发的短期 STS 凭证或预签名请求。

不使用已经停止新购和服务的腾讯云 API 网关。公网入口必须提供 HTTPS、限流和健康检查，可由 CLB 或部署平台入口承担。

## 数据边界

- 本地模式无需账号，监听、历史、配置和局域网共享完整可用。
- 云端模式只同步个人配置、团队配置、目录、排序、附件元数据和墓碑；普通历史不上传。
- 模式切换不搬迁数据；迁移向导只创建副本。
- 本地变更先提交 SQLite 和 Outbox，远端故障不能回滚或阻塞本地操作。
- 服务端生成 Personal/Team Workspace UUID；现有本机 Team Workspace 不自动升级。

## 身份与权限

第一版仅允许平台内部开通邮箱密码账号。刷新令牌存 Windows Credential Manager，数据库、设置和日志禁止记录密码或令牌。服务端按 Workspace、Owner/Admin/Member 和成员分组执行权限；客户端隐藏按钮不构成授权。

所有服务端写操作携带幂等操作 ID 和期望版本。高风险操作二次确认并写审计日志。邀请码只保存 SHA-256 哈希。冲突生成副本，删除使用墓碑。

## 附件

单文件 100 MB；个人默认 1 GB，团队默认 5 GB。采用 SHA-256 内容寻址、可恢复上传、文件名/MIME/扩展名/文件头交叉校验。完成校验前引用保持 Pending，可疑对象进入 Quarantined。下载先写临时文件、校验哈希后原子替换。

## 密钥管理

部署密钥仅允许位于运维主机的 DPAPI 或 CI Secret 中。当前本机凭据文件位于应用数据目录之外，不复制到仓库、发布包或公共网盘。生产运行时优先使用腾讯云实例角色/服务角色，避免长期密钥落盘。

## 后果

本方案多一个自管 API 服务，但避免客户端直接访问数据库、绕过授权或泄漏长期云密钥，也避免绑定已退役的 API 网关。云端服务可以独立关闭，客户端自动退回本地能力。
